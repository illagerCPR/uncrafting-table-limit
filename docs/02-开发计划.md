## 1. 交付物与范围

一个 NeoForge 1.21.1 附属模组，给暮色森林的拆解台加**可配置、互斥**的使用限制。

| 模式（枚举 `mode`） | 行为 | 默认 |
| --- | --- | --- |
| `COOLDOWN` | 每次拆解成功后，该玩家需等待 `cooldown_ticks` 才能再次拆解 | **默认**，`cooldown_ticks = 24000` |
| `DISABLED` | 禁止从拆解格取出任何产物（界面仍可打开预览） | 可选 |
| `DURABILITY` | 每座拆解台有独立耐久，每次拆解扣 `durability_per_use`，耗尽按 `on_deplete` 处理 | 可选 |
| `ITEM_COST` | 每次拆解额外消耗玩家物品栏中的指定物品 | 可选 |

**首版不做**：客户端倒计时/耐久条渲染、拆解台以外的方块限制、修改暮色森林自身配置或协议、白名单绕过。

  - 主类 + 配置骨架（`ModConfigSpec`，`mode` 枚举与各模式参数）
  - **注入验证探针**：`UncraftingMenu#clicked` 上的最小 `@Inject(HEAD)`，仅在 DEBUG 日志里打印一行（证明 Mixin 真的生效）
  - `devmods/`（gitignore）+ `runtimeOnly files(...)` 接入 RDPMouse（WSLg 下 `runClient` 鼠标捕获问题）
  - `.github/workflows/build.yml`（JDK 21 + `./gradlew build`）
  - `README.md`、`AGENTS.md`（登记本文件 §2 的硬事实）
- **验收**：`./gradlew build` 产出 jar；`runGameTestServer` 冒烟测试全绿；**启动日志里能看到 Mixin 应用成功 + 探针日志真的被打印**（R7 的强制闸门）；CI 首次变绿。
- **风险**：Mixin refmap / 混淆名（若失败，日志会明确报 `mixin apply failed`，据此调整 `refmap` 或注解处理器配置）。

### M1 · 模式 A：全局冷却

- **交付**：`mode=COOLDOWN` 全链路 —— 时间戳存储（Data Attachment 或世界 SavedData）、`clicked` HEAD 处的槽位重定向复刻与判定、成功后刷新时间戳、动作栏剩余时间提示（含 `feedback_min_interval` 限流）、`exempt_creative` 创造豁免；冷却换算抽成纯函数。
- **验收**：GameTest G1–G4、G8 全绿（首次可拆 → 立刻再拆被拒 → 时间戳过期后可拆）；`runClient` 人工确认提示文案与手感。
- **验收结果（2026-10-13 回填）**：✅ `runGameTestServer` **All 6 required tests passed**（smoke + G1/G2/G3/G4/G8）；异常日志仅剩 VersionChecker PKIX 已知无害项。G3 的拒绝行为与时间戳写入构成 Mixin 生效的行为学证明。实现要点：冷却存 per-player Data Attachment（`copyOnDeath` 防死亡重置）、HEAD 复刻 TF 槽位重定向判定、RETURN 以 tinkerInput 数量递减检测成功（拆解格会被立即重灌，不可用）、动作栏提示带 `feedback_min_interval` 限流、热路径 fail-open。`runClient` 人工验收（文案与手感）待用户进行。

### M2 · 模式 B：禁止拆解

- **交付**：`mode=DISABLED` —— 同一挂钩点无条件拒绝取物；打开界面时的提示；可选 `block_menu_open`（连界面一起禁止，走 `RightClickBlock`）。
- **验收**：GameTest G5（含"界面仍可打开"的断言）；确认普通配方重铸/修复路径**不受影响**（这是最容易误伤的回归点，必须显式成测）。
- **验收结果（2026-10-13 回填）**：✅ `runGameTestServer` **All 9 required tests passed**（含 G5、`block_menu_open` 事件拒绝测试、以及重铸路径在"冷却中/DISABLED"双状态下的显式回归）。实现：mixin `DISABLED` 分支 + `DisabledModeInteract`（`@EventBusSubscriber` GAME 总线，`setUseBlock(TriState.FALSE)` 拒开界面，`TriState` 无 `DENY` 常量）。`runClient` 人工验收待用户进行。

### M3 · 模式 C：使用耐久

- **交付**：`UncraftingBlockEntity`（耐久值 + `saveAdditional`/`loadAdditional`）；自己的 `BlockEntityType` 注册并在 mod bus 用 `BlockEntityTypeAddBlocksEvent` 绑定 `twilightforest:uncrafting_table`；Mixin 给 `UncraftingTableBlock` 织入 `EntityBlock#newBlockEntity`；每次成功拆解扣耐久；耗尽按 `on_deplete`（`destroy` / `disable`）处理；方块被破坏时把剩余耐久写进掉落物（拆掉再放回不重置）；客户端同步当前耐久用于提示。
- **验收**：GameTest G6–G7 + `level.getBlockEntity(pos) != null` 断言；确认方块破坏/掉落链路无异常（`runGameTestServer` 日志无 NPE）。

### M4 · 模式 D：物品代价

- **交付**：`ITEM_COST` —— 从玩家物品栏按配置扣除指定物品（列表为空时该模式不可用并在日志警告）；不足时拒绝并提示。
- **验收**：GameTest 覆盖"有料放行 / 缺料拒绝 / 创造豁免"。

### M5 · 打磨与发布

- **交付**：中英文 lang（`en_us` / `zh_cn`）；配置注释与 README 配置表；版本号递增；`CHANGELOG.md`；GitHub Release（含 jar 附件）。
- **验收**：全新环境下"只装 TF + 本模组"能正常启动并生效；配置项逐个自测；发布 tag 带 GPG 签名。

## 4. 配置设计（草案）

```toml
# config/uncraftinglimit-common.toml
mode = "COOLDOWN"                  # COOLDOWN | DISABLED | DURABILITY | ITEM_COST
exempt_creative = false            # 创造模式玩家不受限制
notify_player = true               # 被拒时给动作栏提示
feedback_min_interval = 20         # 提示限流（ticks），防止刷屏

[cooldown]
cooldown_ticks = 24000             # 默认 1 游戏日

[disabled]
block_menu_open = false            # true = 连界面一起禁止
message = "uncraftinglimit.message.disabled"   # 语言键，可改写

[durability]
max_durability = 1000
durability_per_use = 1
on_deplete = "destroy"             # destroy | disable
warn_threshold = 50                # 剩余低于该值时开始提示

[item_cost]
item_cost_entries = []             # 形如 ["minecraft:diamond:1", "minecraft:amethyst_shard:2"]
```

## 6. 验证与验收纪律

1. **签名先于代码**：动任何 Mixin 目标前，用 `javap -cp <TF 发布版 jar>` 复核方法存在性与签名。
2. **Mixin 生效必须显式证明**：不接受"Mixin 没报错就是生效了"，每批次都要在启动日志里看到应用记录。
3. **GameTest 全绿 ≠ 无异常**：跑完必须 grep `exception` / `ERROR`（卸载期 NPE 不计入结果）。
4. **热路径 fail-open**：策略代码异常一律放行 + 限流记日志，绝不因限制逻辑让玩家崩档。
5. **不静默删除玩家物品**：耐久耗尽的销毁行为必须提前提示（动作栏警告阈值）。
6. **观感与手感**：文字提示、提示频率、失效反馈走 `runClient` 人工验收。
7. **版本号唯一来源**：`gradle.properties` 的 `mod_version`。
8. **Git 纪律**：commit / tag 用 GPG 签名；推送使用 GitHub 隐私邮箱 `63698328+illagerCPR@users.noreply.github.com`。
